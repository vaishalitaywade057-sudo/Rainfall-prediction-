## 📌 About the Project

Rainfall Prediction is a Machine Learning project that predicts whether it will rain tomorrow based on historical weather conditions.

The project uses weather parameters such as temperature, humidity, atmospheric pressure, wind speed, and rainfall to train machine learning models and make predictions.

The main objective is to explore different ML algorithms and identify effective approaches for rainfall prediction.

## 🎯 Project Objectives

- Analyze historical Australian weather data.
- Perform data cleaning and preprocessing.
- Explore weather patterns through data visualization.
- Implement and compare multiple Machine Learning algorithms.
- Predict whether rainfall will occur the next day.
- Evaluate model performance using standard classification metrics.

## 📊 Dataset Information

**Dataset:** Rain in Australia (WeatherAUS)

**File:** `weatherAUS.csv`

**Records:** 145,460 rows

**Features:** 23 columns

**Target Variable:** `RainTomorrow`

The target variable has two possible outcomes:

- Yes – Rain is expected tomorrow.
- No – Rain is not expected tomorrow.

## 🤖 Machine Learning Algorithms Used

The project explores the following algorithms:

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree Classifier
4. Support Vector Machine (SVM)
5. Random Forest Classifier
6. Artificial Neural Network (ANN)
